# ji documentation

`ji` is a TUI and CLI for managing [Jujutsu (jj)](https://jj-vcs.github.io) workspaces on macOS. It gives you a workspace switcher with a live commit graph, adaptive sync / transfer / close operations, per-project hooks and file templates, and shell integration that moves your shell's working directory when you switch workspaces.

## Assumed knowledge

The docs assume you already know jj — ji is a tool for people who work with jj daily. When a jj concept is relevant to ji's behavior, each page defines ji-specific usage briefly on first use and links to the [official jj documentation](https://docs.jj-vcs.dev/latest/) for the underlying concept (revsets, bookmarks, change IDs, operation log, templates). The [operations.md](operations.md#terminology) page is the canonical glossary for ji-specific terminology (`default@`, effective head, trivial head, step-forward commit, confluence merge, singular bookmark, adaptive method).
